// 01 — Installation

Download & Install LM Studio

LM Studio is a desktop app that bundles everything you need: a model hub, an OpenAI-compatible server, and a chat UI. No Python or Docker required.

01

Check System Requirements

Before downloading, verify your machine meets the minimum specs. GPU acceleration is strongly recommended for usable speeds.

Minimum
  • Windows 10 64-bit (build 1903+)
  • 16 GB RAM (system)
  • 10 GB free disk space
  • Any GPU or CPU-only mode
  • Intel/AMD CPU — AVX2 support
Recommended
  • Windows 11 64-bit
  • 32 GB+ RAM
  • SSD with 50 GB+ space
  • NVIDIA GPU with 8 GB+ VRAM
  • CUDA 12.x drivers
AVX2 is required. Open PowerShell and run Get-WmiObject Win32_Processor | Select-Object -Expand Name then check CPU on Intel ARK or AMD specs to confirm AVX2 support. Nearly all CPUs from 2013+ have it.
02

Download the Installer

Go to the official LM Studio website and grab the Windows installer (.exe). Always download from the official source.

powershell
# Option A: Download via browser # → https://lmstudio.ai → Click "Download for Windows" # Option B: Download with PowerShell (replace version as needed) $url = "https://releases.lmstudio.ai/windows/LM-Studio-0.3.x-Setup.exe" $dest = "$env:USERPROFILE\Downloads\LM-Studio-Setup.exe" Invoke-WebRequest -Uri $url -OutFile $dest Start-Process $dest
LM Studio also ships a portable .zip version — useful for USB drives or if you don't have admin rights. Extract and run lm-studio.exe directly.
03

Run the Installer

Double-click the downloaded .exe. If Windows SmartScreen appears, click More info → Run anyway — LM Studio is unsigned but safe.

  • Accept the license agreement
  • Choose install path (default: C:\Users\You\AppData\Local\Programs\LM Studio)
  • Check "Create desktop shortcut" and "Start at login" (optional)
  • Click Install — takes under 60 seconds
  • Launch LM Studio when prompted
04

Install the CLI (lms)

LM Studio ships with a powerful command-line interface. Enable it once from the app, then use it from any terminal.

powershell
# From LM Studio app: Developer tab → "Enable CLI" button # This adds lms to your PATH. Then in PowerShell: lms --version # confirm install lms status # check server status lms ls # list downloaded models
05

Configure GPU Acceleration

This is the single biggest performance lever. LM Studio auto-detects your GPU but you should verify the backend.

// 02 — Capacity Planning

System Capacity Planning

Choosing a model that fits your hardware is critical. The wrong choice means slow generation, OOM crashes, or degraded quality from over-quantization.

The VRAM Formula
VRAMneeded = (Params × Bits/8) + (ctx × 0.5 MB)
Example: 7B model at Q4_K_M (4 bits) + 4096 ctx = (7×10⁹ × 4/8) ÷ 10⁹ + 2 ≈ 5.5 GB VRAM

~4 bits/param

~6 bits/param

full quality

Pro 16 GB 64 GB 13B Q6 / 34B Q4_K_M 25–40 tok/s RTX 3090/4080, excellent quality
Max 24 GB+ 128 GB 70B Q4 / 34B Q8 / MoE 10–25 tok/s RTX 3090/4090, top-tier output
CPU None 32 GB+ 7B Q4_K_M (RAM-based) 2–8 tok/s Slow but works; needs fast RAM

Key Performance Settings

Context Length (ctx)

Larger context = more VRAM + slower speed. Don't set higher than you need.

2048 ctxminimal VRAM impact
4096 ctx+~0.5 GB VRAM
8192 ctx+~2 GB VRAM
32768 ctx+~8 GB VRAM
GPU Layers Offloading

Layers offloaded to GPU run ~10× faster than CPU. Set to -1 for auto-max.

0 layers (CPU)2–6 tok/s
50% layers GPU12–20 tok/s
100% layers GPU25–55 tok/s
If the model doesn't fully fit in VRAM, LM Studio automatically splits layers between VRAM and RAM.

// 04 — Loading Models

Download & Load a Model

You can discover and load models directly from the LM Studio UI, the CLI, or by pointing to a local GGUF file.

1

Open the Discover Tab

Click the 🔍 Search (magnifying glass) icon in the left sidebar to open the model discovery panel.

2

Search for a Model

Type a model name in the search bar (e.g., qwen2.5-coder). Results pull from Hugging Face. Use filters to narrow by size and quantization.

3

Select a GGUF Variant

Expand the model card, choose a quant variant (look for Q4_K_M or Q5_K_M), and click Download.

LM Studio shows the file size before download and estimates if it fits in your VRAM — pay attention to the green/yellow/red indicators.
4

Load the Model

After download, switch to the Chat tab. Click the model selector at the top, choose your model, and wait for the green "Model loaded" indicator. You're ready.

powershell — lms CLI
# Search for available models lms search "qwen2.5-coder" # Download a specific model (auto-picks best quant for your hardware) lms get Qwen/Qwen2.5-Coder-7B-Instruct-GGUF # Download a specific quantization lms get Qwen/Qwen2.5-Coder-7B-Instruct-GGUF --quant q4_k_m # List all downloaded models lms ls # Load a model into the server lms load qwen2.5-coder-7b-instruct # Load with custom context length lms load qwen2.5-coder-7b-instruct --context-length 8192 # Unload to free VRAM lms unload --all # Quick chat from terminal lms chat --model qwen2.5-coder-7b-instruct

If you've downloaded a GGUF file manually (e.g., from Hugging Face website), point LM Studio to it.

file structure
# Default model directory (customizable in Settings) C:\Users\YourName\.cache\lm-studio\models\ └── lmstudio-community\ └── Qwen2.5-Coder-7B-Instruct-GGUF\ ├── qwen2.5-coder-7b-instruct-q4_k_m.gguf ← main file └── README.md
  • Download the .gguf file from Hugging Face (any model page → Files tab)
  • Place it inside the .cache\lm-studio\models\author\model-name\ folder
  • In LM Studio, go to My Models tab — it will appear automatically
  • Alternatively use Settings → Change models folder to point to a custom directory
// 05 — VS Code Integration

Integrate with VS Code

LM Studio exposes an OpenAI-compatible REST API on localhost:1234. Any VS Code AI extension that supports custom endpoints can use it.

⚡
First: Start the Local Server

In LM Studio, click the ↔ Developer tab in the left sidebar → click Start Server. You'll see it bind to http://localhost:1234. Keep LM Studio running in the background while coding.

🔵
Continue.dev Extension

The best open-source AI coding assistant for VS Code. Supports inline completion, chat, and code edits powered by your local model.

1. Install the extension
vs code command palette
ext install Continue.continue
2. Edit ~/.continue/config.json
json
{ "models": [{ "title": "LM Studio", "provider": "lmstudio", "model": "AUTODETECT" }], "tabAutocompleteModel": { "title": "Qwen2.5-Coder", "provider": "lmstudio", "model": "qwen2.5-coder-7b-instruct" } }
Continue has a built-in LM Studio provider — no URL config needed. It auto-discovers the running model.
🟢
Cline (Claude-like Agent)

Cline is an agentic coding assistant that can read/write files, run commands, and browse. Works with local models via OpenAI-compatible API.

1. Install Cline
vs code command palette
ext install saoudrizwan.claude-dev
2. Configure in Cline Settings
  • API Provider: OpenAI Compatible
  • Base URL: http://localhost:1234/v1
  • API Key: lm-studio (any value)
  • Model: qwen2.5-coder-7b-instruct

Any OpenAI-Compatible Extension

Almost any AI coding tool (Copilot alternatives, chat plugins) that supports a custom OpenAI endpoint works out-of-the-box with LM Studio's local server.

connection details
Base URL : http://localhost:1234/v1 API Key : lm-studio # any string, it is ignored Model ID : your-model-name # match exactly what lms ps shows # Test with curl (PowerShell) curl http://localhost:1234/v1/chat/completions ` -H "Content-Type: application/json" ` -d '{"model":"qwen2.5-coder-7b-instruct","messages":[{"role":"user","content":"Hello!"}]}'
// 06 — API & Code Integration

Use LM Studio from Code

The local server is fully OpenAI-compatible. Drop in your existing OpenAI code and change the base URL — nothing else needs to change.

python
from openai import OpenAI # Point the openai client at LM Studio client = OpenAI( base_url="http://localhost:1234/v1", api_key="lm-studio" # ignored, can be anything ) # Standard chat completion — identical to openai API response = client.chat.completions.create( model="qwen2.5-coder-7b-instruct", messages=[ {"role": "system", "content": "You are a helpful coding assistant."}, {"role": "user", "content": "Write a Python function to reverse a linked list."} ], temperature=0.7, max_tokens=1024 ) print(response.choices[0].message.content) # Streaming response stream = client.chat.completions.create( model="qwen2.5-coder-7b-instruct", messages=[{"role": "user", "content": "Explain async/await in Python"}], stream=True ) for chunk in stream: print(chunk.choices[0].delta.content or "", end="", flush=True)
javascript / node.js
import OpenAI from 'openai'; // npm install openai const client = new OpenAI({ baseURL: 'http://localhost:1234/v1', apiKey: 'lm-studio', }); // Chat completion const completion = await client.chat.completions.create({ model: 'qwen2.5-coder-7b-instruct', messages: [ { role: 'system', content: 'You are a helpful coding assistant.' }, { role: 'user', content: 'Generate a REST API in Express.js' } ], temperature: 0.7, }); console.log(completion.choices[0].message.content); // Streaming const stream = await client.chat.completions.create({ model: 'qwen2.5-coder-7b-instruct', messages: [{ role: 'user', content: 'Write a quicksort in TypeScript' }], stream: true, }); for await (const chunk of stream) { process.stdout.write(chunk.choices[0]?.delta?.content ?? ''); }
c# — using openai .net sdk
// dotnet add package OpenAI using OpenAI; using OpenAI.Chat; var client = new OpenAIClient( new Uri("http://localhost:1234/v1"), new ApiKeyCredential("lm-studio") ); var chatClient = client.GetChatClient("qwen2.5-coder-7b-instruct"); var response = await chatClient.CompleteChatAsync( new[] { new SystemChatMessage("You are a helpful coding assistant."), new UserChatMessage("How do I use LINQ in C#?"), } ); Console.WriteLine(response.Value.Content[0].Text);
Available Endpoints: LM Studio supports GET /v1/models, POST /v1/chat/completions, POST /v1/completions, and POST /v1/embeddings — covering virtually all use cases including RAG pipelines with local embeddings.
